Defenses

Agent memory

This is a simulation with a fixed script, not a live model. The agent here obeys everything it reads, which is the assumption a defense should be designed for. The rules match the open-source memgate library this page ships with.

The ideas are not ours alone. Binding a memory's authority to its origin is formalised in TMA-NM, and a confirmation gate for untrusted memory appears in PerMIT. What this page adds is the month-long view: notes, merges and expiry.
